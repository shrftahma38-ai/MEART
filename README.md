# MEART — قالب وردپرس «گوشت شهروند»

قالب فارسی و راست‌چین برای فروشگاه گوشت و پروتئین، همراه با محیط اجرای آزمایشی روی وردپرس.

| مسیر | توضیح |
| --- | --- |
| `theme/goosht-shahrvand/` | سورس قالب وردپرس (همان چیزی که در ZIP نصبی قرار می‌گیرد) |
| `scripts/build-theme-zip.sh` | ساخت فایل نصبی `dist/goosht-shahrvand-wordpress-theme.zip` |
| `dist/` | فایل نصبی ساخته‌شده + صفحه دانلود؛ همین پوشه در پیش‌نمایش روی نشانی `/download/` سرو می‌شود |
| `sandbox/` | فقط برای محیط آزمایشی: تنظیمات وردپرس، اسکریپت محتوای نمونه و تصاویر نمونه |
| `docker-compose.base44.yml` | وردپرس + MySQL + اجرای محتوای نمونه |

## ساخت فایل نصبی قالب

```bash
sh scripts/build-theme-zip.sh
# خروجی: dist/goosht-shahrvand-wordpress-theme.zip
```

ساختار ZIP بررسی می‌شود: تنها یک پوشه بالادستی (`goosht-shahrvand/`)، وجود فایل‌های ضروری
(`style.css`, `functions.php`, `screenshot.png`, قلم‌ها و …) و نبود فایل خراب یا اضافه.

## نصب در وردپرس

1. پیشخوان وردپرس → **نمایش → پوسته‌ها → افزودن پوسته → بارگذاری پوسته**
2. فایل `goosht-shahrvand-wordpress-theme.zip` را انتخاب و **اکنون نصب کن** را بزنید.
3. **فعال کردن** قالب.

پس از فعال‌سازی، تنظیمات قالب از مسیر **نمایش → سفارشی‌سازی → تنظیمات قالب گوشت شهروند**
(رنگ‌ها، اطلاعات تماس، اسلایدر، درباره ما، محصولات، گالری و فوتر) قابل ویرایش است.

> افزونه **ووکامرس همراه قالب ارائه نمی‌شود**. قالب تنها پشتیبانی ووکامرس دارد
> (`add_theme_support('woocommerce')`، قالب کارت محصول و استایل صفحات فروشگاه، سبد خرید و
> تسویه حساب). برای فروشگاه واقعی باید افزونه ووکامرس را جداگانه نصب کنید.

## اجرای محیط آزمایشی (این مخزن)

```bash
docker compose -f docker-compose.base44.yml up -d
```

* وردپرس روی پورت ۳۰۰۰ بالا می‌آید (`http://localhost:3000`).
* سرویس `seed` یک‌بار وردپرس را به فارسی نصب می‌کند، قالب را فعال می‌کند، برگه‌ها و منوها را
  می‌سازد و در صورت دسترسی به اینترنت، ووکامرس و ۶ محصول نمونه را اضافه می‌کند.
* اجرای دوباره محتوای نمونه بی‌خطر است:
  `docker compose -f docker-compose.base44.yml run --rm --no-deps seed sh /seed/seed.sh`
* اطلاعات ورود محیط آزمایشی: `admin` / `base44-demo` (فقط برای همین محیط محلی).

جزئیات فنی محیط و نکات خاص آن در `AGENTS.md` آمده است.

## قلم‌ها و تصاویر

* قلم‌ها داخل قالب و بدون درخواست بیرونی بارگذاری می‌شوند: **Vazirmatn** (متن) و
  **Noto Naskh Arabic** (تیترها)، هر دو با پروانه SIL Open Font License 1.1.
* تصاویر موجود در `assets/images/` تصاویر جایگزین (placeholder) تولیدشده هستند تا طراحی
  کامل نمایش داده شود؛ برای استفاده واقعی، عکس‌های خودتان را از سفارشی‌ساز جایگزین کنید.
